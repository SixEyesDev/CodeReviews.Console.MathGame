# Math Game

This is a console-based math tool I built for **The C# Academy**. It’s designed to let users practice basic math with randomly generated problems.

### What it does
* **Custom Game Length:** You decide how many questions you want to answer per round.
* **Score Tracking:** The app uses a `List` to save your results so you can check your history later in the menu.
* **Random Problems:** Allows the user to choose an operation type (addition, subtraction, etc..) and uses that information to randomly generate a problem of that type. This is done for every problem in the game.
* **Easy Navigation:** After a game, you can either start another round or head back to the menu to view your history, change the number of problems per round, or close the application.

### Technical Focus
* Managing user input in a console window.
* Using collections to store data during a session.
* Building logic that scales based on user choice.
